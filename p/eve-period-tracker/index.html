Eve Period Tracker - 优雅的经期追踪应用

发表于2026-01-01|更新于2026-05-21|APP|健康

Eve Period 是一款面向女性的经期记录与管理应用，采用原生 SwiftUI 构建，提供简洁、私密、可靠的周期追踪体验。

亮点

  • 周期日历 + 智能预测
  • 快速记录开始/结束，并支持备注
  • 本地提醒与邮件提醒，可自定义时间
  • iCloud 私有同步 + JSON 导入/导出
  • 中英文切换，无广告、无追踪

为什么选择它

  • 原生 SwiftUI 体验，流畅快速
  • 数据存放在你的 iCloud 私有空间，端到端加密
  • 免费使用：无广告、无订阅
  • 数据统计清晰：平均周期、最短/最长、下次经期倒计时

快速上手

  1. 点击“经期开始”与“经期结束”完成记录。
  2. 在设置中配置提醒时间与提前天数。
  3. 需要备份/换机时，可随时导出 JSON 或导入迁移。

技术栈

  • SwiftUI + SwiftData，CloudKit 私有数据库
  • UNUserNotificationCenter 本地提醒，支持可选的邮件提醒
