Monster Chores - Chore Points and Rewards

Created2026-01-02|Updated2026-06-03|APP
  • Make chores fun: chore lists + points + rewards.
  • Assign chores, review completion, and turn effort into points.
  • A clean family chore and reward tracker with optional iCloud family sync.

Brief Introduction

Monster Chores helps families turn daily chores into a simple “points + rewards” system. Parents create chores and rewards, children complete chores (optionally uploading photos), and parents review them before awarding points. It supports progress statistics and optional iCloud sync to share family data across devices.

What It Can Do (Overview)

  • Create chore tasks: set points and repeat frequency (once/daily/weekly).
  • Children mark tasks as completed, and parents review and confirm point rewards.
  • Track point transactions and redeem rewards in the family “store”.
  • View weekly activity charts and a simple leaderboard.
  • Support multiple children and switching between different roles/accounts.
  • Support JSON import/export for backup and recovery.

Core Features (Store Copy)

  • Parent/Child Roles: Clear assignment and completion of responsibilities.
  • Review System: Pending review list, view details, and approve with one tap to award points.
  • Points and Transaction History: Record the full history of points earned/spent/adjusted.
  • Reward Store: Define rewards, set point costs, and complete redemptions.
  • Statistics and Charts: Weekly activity, points for the current week, and recent completion records.
  • Family Management: Create families, invite members, and switch families.
  • Optional iCloud Sync: Share family data through iCloud/CloudKit (invitation link).
  • Data Migration Supported: JSON export/import (note: photos are not included in JSON).

Value Points

  • More Motivation: Points and rewards make habits easier to maintain.
  • More Fairness: Reviews + history keep rules consistent.
  • More Visibility: Children can see progress, and parents can see trends.
  • Optional Sync: Local use by default; enable iCloud Family Sharing only when needed.
