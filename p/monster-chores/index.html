Monster Chores - 家务任务积分与奖励

发表于2026-01-02|更新于2026-05-21|APP
  • 让家务变有趣：家务清单 + 积分 + 奖励。
  • 分配家务、审核完成，把努力变成积分。
  • 简洁的家庭家务与奖励追踪器，可选 iCloud 家庭同步。

简短介绍

Monster Chores 帮助家庭把日常家务变成“积分 + 奖励”的简单体系。家长创建家务与奖励，孩子完成家务（可选上传照片），家长审核后发放积分。支持统计进度，并可选用 iCloud 在多设备间同步家庭数据。

它能做什么（概览）

  • 创建家务任务：设置积分与重复频率（一次/每天/每周）。
  • 孩子标记完成，家长审核并确认发放积分。
  • 记录积分流水，并在家庭“商店”兑换奖励。
  • 查看每周活跃图表与简单排行榜。
  • 支持多个孩子与不同角色/账号切换。
  • 支持 JSON 导入/导出进行备份与恢复。

核心功能（商店文案）

  • 家长/孩子角色：分配与完成职责清晰。
  • 审核机制：待审核列表，查看详情，一键通过发放积分。
  • 积分与流水：记录获得/花费/调整的完整历史。
  • 奖励商店：定义奖励、设置积分成本、完成兑换。
  • 统计与图表：每周活跃、当周积分、最近完成记录。
  • 家庭管理：创建家庭、邀请成员、切换家庭。
  • 可选 iCloud 同步：通过 iCloud/CloudKit 共享家庭数据（邀请链接）。
  • 数据可迁移：JSON 导出/导入（注意：照片不包含在 JSON 中）。

价值点

  • 更有动力：积分与奖励让习惯更容易坚持。
  • 更公平：审核 + 历史记录让规则一致。
  • 更可视：孩子看进度，家长看趋势。
  • 可选同步：默认本地使用，需要时再开启 iCloud 家庭共享。

关键词（元数据）
