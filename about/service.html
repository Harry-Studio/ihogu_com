服务范围

AI 应用开发 / 落地
把模型真正接到业务里：可用、可控、可持续迭代
  • 企业知识库/RAG：文档问答、客服助手、内部检索（权限/日志/可追溯）
  • Agent/工作流：多步骤自动化、工具调用、报表生成、内容生产
  • 开源模型部署：Ollama / vLLM / GPU 推理部署、推理加速与成本优化
  • ComfyUI 工作流：AIGC 图像批处理、海报/电商图、自动出图管线
移动端 / 小程序
面向增长与转化的端侧体验与稳定性
  • Android / iOS App 设计与开发（含上架协助）
  • 微信 / 支付宝 / 抖音小程序：下单、预约、会员、内容、工具类
  • 小游戏：答题、合成、经营、休闲类玩法与活动页
H5 / 公众号 / Web
活动页、官网、表单、内容系统与业务后台
  • H5 活动页/落地页：数据统计、分享裂变、表单收集
  • 公众号开发：菜单、消息、支付、模板消息/订阅消息
  • 管理后台：权限、订单、内容、数据面板
自动化 / 工具 / 插件
提升效率，把重复工作“程序化”
  • 办公自动化：Python + Excel + 报表/爬取/对账/批处理
  • 浏览器插件 / 油猴脚本：采集、填表、批量操作、工作台增强
  • 技术选型顾问：低代码评估、数据库/架构建议、可行性拆解
部署 / 运维 / 配套
从上线到稳定运行：可观测、可扩展
  • 服务器部署/优化：Nginx、HTTPS、CDN、日志与告警
  • 域名注册、ICP备案、企业邮箱等配套支持
  • 长期维护：迭代、Bug 修复、性能与安全加固

合作流程

1. 需求沟通 → 产出功能清单/报价/排期
2. 原型与方案 → 确认页面/交互/接口
3. 开发联调 → 周期内同步进度与可演示版本
4. 上线交付 → 部署、文档、培训与售后维护
